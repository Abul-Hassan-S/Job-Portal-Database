# Online Job Portal Application - Database Design & Testing

## Project Overview
Designed and managed a complete relational database for a Job Portal 
Application. Created tables, wrote and validated SQL queries to store 
and retrieve data related to Users, Recruiters, Job Postings and 
Applications.

## Database Tables Created
- Users
- Recruiters
- Jobs
- Applications

## SQL Queries Written & Validated

### DDL - Data Definition Language
- CREATE TABLE for all 4 tables
- ALTER TABLE to modify columns
- DROP TABLE to remove tables

### DML - Data Manipulation Language
- INSERT data into all tables
- UPDATE records based on conditions
- DELETE records based on status

### DQL - Data Query Language
- SELECT with WHERE conditions
- JOIN queries across multiple tables
- Filter jobs by location and salary

### TCL - Transaction Control Language
- COMMIT to save transactions
- ROLLBACK to undo changes

### DCL - Data Control Language
- GRANT permissions to users
- REVOKE permissions from users

## Testing Performed
- Data Integrity Testing
- Backend Database Testing
- Query Validation Testing
- Foreign Key Constraint Testing
- Duplicate Entry Validation

- MySQL
- SQL Workbench
